# Contributing

This repository is published automatically from Bopsy's own (private) repo, and each publish replaces its contents.
A pull request here would be overwritten by the next publish, so please
[open an issue](https://github.com/Elevaite-AI/bopsy-skills/issues) instead: a bug in `bopsy-skill`, a rule that
refuses a package it shouldn't, or something the guide gets wrong. We'll make the change at the source.
